# The StyleRealm — website

Landing page for **thestylerealm.com**, hosted on GitHub Pages.

- `index.html` — the mobile-first landing page (single file: styles, scripts and images inline)
- `media/process-video.mp4` — "Srinethi explains the process" video (720p web version, ~43 MB)
- `CNAME` — custom domain for GitHub Pages

To update the site: edit `index.html`, commit and push to `main`. GitHub Pages republishes within a minute or two.
